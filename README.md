Vision Guided Pick and Place Robot Read Me FileNeeded environments/setups- python3(https://www.python.org/downloads/)- matlab(https://www.mathworks.com/help/install/ug/install-products-with-internet-connection.html)- webots(https://cyberbotics.com/)Open Webots applicationsTo open the simulation file, follow the following steps1) File > Open World > (Navigate to project directory) > worlds > UR5.wbt2) Install NumPy and sympyBy default you will see the robot performing a pick and place demo of all 3 blocks. To watch the dynamics study discussed in the project video, navigate to line 42 in robot_controller.py and set the RUN_SEQUENTIAL_PAYLOAD_BENCHMARK = True
